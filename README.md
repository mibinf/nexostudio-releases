# NexoStudio releases

NexoStudio is a desktop application for self-employed professionals and small businesses, created by [MIB Informática](https://mibinf.com.br). It brings customer records, history, scheduling, costs and cash management together, with local data storage and backup and restoration. Its local features work without an account or an internet connection. The interface is in Brazilian Portuguese.

This public repository distributes compiled Electron application artifacts through GitHub Releases. The application source code and development history are maintained separately in a private repository.

## Download

Visit [Releases](https://github.com/mibinf/nexostudio-releases/releases) and choose a published version. Download the installer or package listed under **Assets** for your operating system and processor architecture, and follow that release's installation notes.

Only the platforms and architectures explicitly listed in a release are available for that version. If no release is published, a public download is not yet available.

GitHub's automatically generated **Source code (zip)** and **Source code (tar.gz)** archives contain this repository's documentation, not the application source code or an installer.

Back up your data before installing an update. Development releases may change the database structure; installing an older application version does not convert newer data back to an older format.

## Repository contents

The Git history of this repository contains only `README.md` and `LICENSE`. Installers, packages and update metadata belong in release assets, not in Git commits. Source code, credentials, customer data and backups must not be published here.
